Health Lens: Health Base Prediction using Machine Learning

Health Lens is a machine learning-based project aimed at predicting the likelihood of various diseases, such as Diabetes, Heart Disease, and Parkinson's Disease. The goal is to assist healthcare professionals and individuals in early diagnosis, enabling timely treatment and improved health outcomes.

## 🚀 How to Set Up the Project

1. Clone the Repository
git clone https://github.com/samikshaguptaa/Health-Lens-ML.git
cd HealthLens

2. Create and Activate a Virtual Environment
  On Windows:
  python -m venv venv
  venv\Scripts\activate

  On macOS/Linux:
  python3 -m venv venv
  source venv/bin/activate

3. Install Required Dependencies
  pip install -r requirements.txt
